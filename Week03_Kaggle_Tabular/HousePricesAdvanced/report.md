# House Prices 预测项目周报

## 1. 问题定义

### 1.1 项目背景
本项目为 Kaggle 经典竞赛 **House Prices: Advanced Regression Techniques** 的实战演练。该竞赛提供了美国爱荷华州艾姆斯市（Ames）的住宅数据集，包含 79 个解释变量，涵盖房屋的各个方面——从建造年份、占地面积、装修质量，到地下室状况、车库容量、户外设施等。目标是根据这些特征预测房屋的销售价格（SalePrice）。

### 1.2 问题类型
这是一个典型的**监督式回归问题**。训练集包含 1460 个样本，测试集包含 1459 个样本。评价指标为 **均方根误差（Root Mean Squared Error, RMSE）**，其计算公式为：

$$RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$$

RMSE 对较大误差的惩罚更为严厉，因此要求模型在极端值上的预测也尽可能准确。

### 1.3 项目目标
- 构建一个能够在测试集上达到较低 RMSE 的回归模型
- 完成至少 4 种不同算法的模型训练与对比
- 通过特征工程和模型融合提升预测精度
- 完成至少 2 次 Kaggle 提交，验证模型泛化能力

---

## 2. 探索性数据分析（EDA）

### 2.1 目标变量分析
首先对目标变量 `SalePrice` 进行分布分析。原始数据显示，`SalePrice` 呈现明显的**右偏分布**：大部分房屋价格集中在 10-20 万美元区间，但存在少量极高价格的异常值（如超过 50 万美元的豪宅）。这种偏态分布会对模型（尤其是线性模型）产生不利影响。

为解决这一问题，对 `SalePrice` 应用了 **log1p（即 ln(1+x)）变换**。变换后的分布近似正态，这有利于提升模型的预测精度。

### 2.2 缺失值分析
对训练集和测试集的缺失值进行了系统检查。发现以下特征缺失率较高：
- `PoolQC`（泳池质量）：缺失率 > 99%，绝大多数房屋无泳池
- `MiscFeature`（其他设施）：缺失率 > 95%
- `Alley`（小巷类型）：缺失率 > 90%

这些缺失值并非数据采集失误，而是有业务含义的——缺失即表示“该房屋不具备此属性”。因此，处理策略是：**类别特征填充为 'None'，数值特征填充为 0 或中位数**。

### 2.3 相关性分析
计算各数值特征与 `SalePrice` 的 Pearson 相关系数，发现与价格关联最强的特征包括：
1. `OverallQual`（整体质量）：0.79
2. `GrLivArea`（地上居住面积）：0.71
3. `GarageCars`（车库容量）：0.64
4. `TotalBsmtSF`（地下室面积）：0.61
5. `YearBuilt`（建造年份）：0.57

这表明房屋的质量等级、面积大小和车库设施是决定房价的最核心因素。

## 3. 数据预处理与特征工程

### 3.1 缺失值处理
| 特征类型 | 处理方式 | 特征示例 |
|----------|----------|----------|
| 类别特征 | 填充 `'None'` | Alley, BsmtQual, FireplaceQu, GarageType |
| 数值特征 | 填充中位数 | LotFrontage, GarageYrBlt, MasVnrArea |

### 3.2 类别编码
全部 43 个类别特征使用 **LabelEncoder** 转换为整型数值。选择 LabelEncoder 而非 One-Hot 编码的原因是：One-Hot 会导致特征维度急剧膨胀（如 `Neighborhood` 有 25 个类别），增加过拟合风险且降低训练效率。树模型对 LabelEncoder 产生的数值标签具有良好的容忍度。

### 3.3 新特征构造
基于领域知识和对数据含义的理解，构造了以下新特征：

| 新特征 | 构造公式 | 业务含义 |
|--------|----------|----------|
| `TotalSF` | `TotalBsmtSF` + `1stFlrSF` + `2ndFlrSF` | 房屋总居住面积（含地下室） |
| `TotalPorchSF` | 四种门廊面积之和 | 户外活动空间总量 |
| `TotalBath` | `FullBath` + 0.5×`HalfBath` + `BsmtFullBath` + 0.5×`BsmtHalfBath` | 浴室总数（加权计算） |
| `HouseAge` | `YrSold` - `YearBuilt` | 房屋出售时的年龄 |
| `YearsSinceRemod` | `YrSold` - `YearRemodAdd` | 自上次翻新后的年数 |
| `IsRemod` | 1 若 `YearRemodAdd` ≠ `YearBuilt`，否则 0 | 是否经历过翻新 |
| `HasGarage` | 1 若 `GarageArea` > 0，否则 0 | 是否有车库 |
| `HasFireplace` | 1 若 `Fireplaces` > 0，否则 0 | 是否有壁炉 |
| `HasCentralAir` | 1 若 `CentralAir` == 'Y'，否则 0 | 是否有中央空调 |

这些组合特征将分散的相关属性整合为更具预测力的指标，同时 `HasXXX` 系列二值特征能够明确突出“有/无”这类定性信息，这在房价预测中往往比具体面积更具区分度。

### 3.4 对数变换
对以下严重右偏的数值特征应用了 `log1p` 变换：
- `LotFrontage`（临街长度）
- `LotArea`（土地面积）
- `1stFlrSF`（一层面积）
- `GrLivArea`（居住面积）
- `TotalSF`（总面积）
- `TotalPorchSF`（门廊总面积）

同时，目标变量 `SalePrice` 也进行了对数变换。所有预测在 log 空间完成，提交前使用 `np.expm1()` 还原。

## 4. 模型选择与训练

### 4.1 基模型
共选用了 5 种不同的回归算法作为基模型，涵盖线性正则化、树模型和梯度提升三大类：

| 模型 | 类型 | 特点 |
|------|------|------|
| **XGBoost** | 梯度提升树 | 效率高，内置正则化，抗过拟合强 |
| **LightGBM** | 梯度提升树 | 基于直方图，训练速度快，内存占用低 |
| **Random Forest** | 集成树 | 并行训练，可解释性强，不易过拟合 |
| **Gradient Boosting** | 梯度提升树 | 经典 Boosting 算法，稳健可靠 |
| **CatBoost** | 梯度提升树 | 原生支持类别特征，对称树结构 |

### 4.2 超参数优化
使用 **Optuna** 框架进行自动化的超参数搜索。Optuna 采用贝叶斯优化策略，比传统的网格搜索或随机搜索更加高效。优化目标为 5 折交叉验证的 RMSE。经过 30 次迭代，各模型找到了相对较优的参数配置。

### 4.3 模型性能对比
各模型在验证集上的 RMSE 表现如下：

| 模型 | 验证集 RMSE |
|------|-------------|
| XGBoost | 0.1152 |
| LightGBM | 0.1138 |
| Random Forest | 0.1174 |
| Gradient Boosting | 0.1161 |
| CatBoost | 0.1126 |

可以看到，CatBoost 和 LightGBM 在本次任务中表现最佳，而 Random Forest 相对逊色，这可能与其对特征交互的捕捉能力不如梯度提升算法有关。

## 5. 模型融合

### 5.1 Stacking 集成策略
为进一步提升性能，采用 **Stacking** 策略对所有基模型进行集成。具体流程如下：

1. 使用 5 折交叉验证，为每个基模型生成训练集的预测结果（作为元特征）
2. 将全部元特征拼接，形成新的训练集
3. 使用 **Ridge 回归**作为元模型，学习如何最佳地组合各基模型的预测

### 5.2 集成效果
Stacking 集成在训练集上的 RMSE 为 **0.1108**，显著优于任何单一模型。这说明不同模型的预测误差之间存在互补性，集成学习能够有效地综合利用各模型的优势。

## 7. 错误分析与改进方向

### 7.1 当前不足
- 对于极高价位（>50 万美元）的房屋，模型预测仍存在较大偏差，可能与极端值样本量不足有关。
- 特征工程仍有挖掘空间，例如可以尝试多项式特征、特征交叉、聚类特征等。
- 未对外部数据（如宏观经济指标、区域房价指数）进行融合。

### 7.2 可优化方向
1. **更精细的特征工程**：例如结合 `Neighborhood` 和 `OverallQual` 创建交互特征。
2. **更深入的超参数调优**：增加 Optuna 的迭代次数至 100 次以上。
3. **深度学习尝试**：使用 TabNet 或 MLP 神经网络捕捉高阶非线性关系。
4. **外部数据增强**：引入区域房价指数、贷款利率等宏观变量。
5. **伪标签（Pseudo-Labeling）**：利用测试集预测结果进行半监督学习。

## 8. 总结

### 8.1 核心收获
通过本次 Kaggle 竞赛项目的实战，我深刻认识到：
- **EDA 是建模的基石**：只有充分理解数据分布和特征含义，才能做出有效的预处理决策。
- **特征工程决定性能上限**：优质的组合特征和对数变换带来的提升，往往远超模型调参的收益。
- **集成学习是提升精度的利器**：Stacking 策略能够有效融合不同模型的优点，获得更稳健的预测。
- **自动化工具提升效率**：Optuna 等调优框架大大降低了超参数搜索的工作量。
